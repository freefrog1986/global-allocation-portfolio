# 决策日志：2026-09-15 — 不连券商

> 类型：项目边界
> 决策者：liubo

## 背景

全球资产配置组合的常见功能是"对接券商账号 → 实时拉持仓 → 提示调仓"。

## 决策

**MVP 不连券商**。这是个研究/回测工具，不是交易终端。

## 不做什么

- 不调券商 API（华泰/国联/IB 等）
- 不查实时持仓
- 不下任何单
- 不划资金

## 为什么

1. **合规风险**：连券商 → 可能被认为是"投资顾问"
2. **测试复杂度**：要 sandbox 账号
3. **数据真实性**：券商数据要看 API 配额
4. **MVP 价值**：回测本身就够个人用了

## 后续

如果未来要加"持仓录入 + 偏离度预警"（spec 045），可以让用户**手动**录入成交（像 etf-rotation 的 `live-fill` 一样），程序不连券商。
