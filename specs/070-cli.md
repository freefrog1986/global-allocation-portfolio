# Spec 070: CLI 接口

> 状态：Draft
> 最后更新：2026-09-15

## 目标

提供统一的命令行入口 `gap`（global-allocation-portfolio 的缩写），让所有功能从终端可用。**不在终端做交互式可视化**——可视化交给飞书卡片（spec 080）。

## 不在范围内

- TUI（Text-based UI）—— 后续 spec 075
- Web UI
- 配置文件可视化编辑

## API 概览

用 [Typer](https://typer.tiangolo.com/) 实现（基于 Click + type hints）。

```bash
# ─── 顶层帮助 ───
gap --help
gap --version

# ─── 策略 ───
gap strategy list                              # 列出内置策略
gap strategy show 60_40                        # 显示某个策略详情
gap strategy validate path/to/my.yaml          # 校验用户自定义策略
gap strategy show path/to/my.yaml              # 显示自定义策略

# ─── 数据 ───
gap data fetch AAPL --period 5y                # 拉单标的
gap data fetch 510300.SH --source akshare      # 指定数据源
gap data list                                  # 列出已缓存的标的
gap data clear AAPL                            # 清某标的缓存
gap data clear --all                           # 清全部

# ─── 回测 ───
gap backtest 60_40 --period 5y                 # 跑单策略
gap backtest 60_40 --start 2018-01-01 --end 2024-12-31 --capital 100000
gap backtest my.yaml --period 5y --cost-bps 30 # 自定义策略 + 自定义手续费

# ─── 对比 ───
gap compare 60_40 permanent_portfolio all_weather --period 5y
gap compare 60_40 my.yaml --period 10y --output comparison.md

# ─── 飞书发图 ───
gap publish 60_40 --period 5y                  # 发当前话题（spec 080）
gap publish 60_40 --period 5y --dry-run        # 预览，不真发
```

## 数据契约

CLI 命令的参数通过 Typer 自动从 type hint 推断。

```python
import typer
from typing import Annotated
from datetime import date
from decimal import Decimal

app = typer.Typer(no_args_is_help=True)

strategy_app = typer.Typer(help="管理策略")
data_app = typer.Typer(help="管理数据")
app.add_typer(strategy_app, name="strategy")
app.add_typer(data_app, name="data")

@strategy_app.command("list")
def strategy_list():
    """列出内置策略。"""
    ...

@strategy_app.command("show")
def strategy_show(
    strategy_id: Annotated[str, typer.Argument(help="策略 ID 或 YAML 文件路径")],
):
    """显示策略详情。"""
    ...

@data_app.command("fetch")
def data_fetch(
    symbol: Annotated[str, typer.Argument()],
    period: Annotated[str, typer.Option("--period", help="1y / 5y / 10y / max")] = "5y",
    source: Annotated[str, typer.Option("--source", help="yfinance / akshare")] = "auto",
):
    """拉取历史数据。"""
    ...
```

## 边界情况

1. **策略 ID 不存在** —— 报错 + 列出可用 ID
2. **YAML 文件不存在** —— 报错 + 退出码 2
3. **YAML 格式错误** —— 显示具体哪个字段错了（pydantic ValidationError）
4. **网络请求失败** —— 重试 3 次（指数退避），仍失败则报错
5. **数据不足** —— 提示用户最少需要多少天
6. **时间区间倒置**（end < start） —— 报错
7. **未配置飞书凭证就 `gap publish`** —— 报错 + 引导到 `docs/feishu-setup.md`

## 验收标准

- [ ] Rich 输出在非 TTY（管道/重定向）下回退纯文本

## 备注

- **不用 argparse** —— Typer 自动从 type hint 生成，自动 `--help`
- **不用 Click 直接** —— Typer 是 Click 的薄包装，更 Pythonic
- **`gap` 作为命令名** —— global-allocation-portfolio 的首字母缩写（global allocation portfolio）
