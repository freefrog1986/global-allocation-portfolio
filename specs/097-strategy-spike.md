## 策略结构（三层 — 第十五轮调整）

### Layer 1（细粒度上限）：14 个 SwensenClass 子类各设上限

规则：**只设上限，不设目标**——子类占比超过上限时触发再平衡提醒。这样留出灵活度，不强制每个子类必须有持仓。

### Layer 2a（投资类目标）：4 个超类的目标比例

| 超类 | 子类数 | 备注 |
| --- | --- | --- |
| **股票**（CN/HK/US/EU/ASIA_DM/EM/GLOBAL_THEMED 共 7 子类） | 7 | 高收益产品，主要配置 |
| **债券**（CN_GOV_BOND/CN_CREDIT_BOND/US_BOND 共 3 子类） | 3 | 防御性配置 |
| **REITs**（CN_REIT/US_REIT 共 2 子类） | 2 | 通胀对冲辅助类 |
| **商品**（COMMODITY 1 子类） | 1 | 通胀对冲辅助类 |

**关键变化（第十五轮）**：4 个投资类之和 < 1.0（默认 97%），剩余由现金区间填充，不强制 = 100%。

### Layer 2b（现金区间 — 第十五轮新增）："子弹"区间策略

**为什么不设固定目标走区间**：
- 股票/债券/REITs/商品属于"投资类"，追求收益
- 现金属于"子弹/弹药"，用于市场大跌时抄底 + 应对突发流动性需求
- 区间策略：常态下子弹不要打光（不低于 20%），但也不要囤太多（不高于 50%，资金有机会成本）

**为什么现金是区间不是目标**：
- 经济危机时需要大量现金抄底（子弹越多越好，但常态下不要打光）
- 现金有"机会成本"（投资收益跑赢现金），囤太多也是浪费
- 区间 [min, max] 提供"硬约束"：超出区间 → 调仓信号
  - 当前 < min：子弹打光了，要警惕（不能继续满仓投资）
  - 当前 > max：子弹囤太多，需要加仓投资类
  - min ≤ 当前 ≤ max：区间内，灵活

## 备注

**为什么是三层结构（第十五轮设计）**：
- Layer 1（上限）给"硬约束"——任何子类超过上限都触发警示，避免单一子类风险过度集中
- Layer 2a（投资目标）给"软引导"——4 个投资类的目标比例反映整体风险偏好（股票 70% = 偏激进）
- Layer 2b（现金区间）给"弹性空间"——常态下子弹保留在区间内，危机时可加仓
- 三层结合：硬约束防止风险 + 软引导反映策略意图 + 弹性区间应对不确定性

**为什么"只设上限不设目标"用于子类**：
- 子类级别如果强制目标比例会过度约束（市场短期波动会频繁触发再平衡）
- 只设上限更稳健：常态下不打扰用户，只在风险集中时介入

**为什么"现金走区间不走固定目标"**（第十五轮核心变化）：
- 现金本质是"子弹"（防御 + 抄底），不是"投资"（追求收益）
- 区间策略给用户保留弹性：常态下 20-50% 都行，但超出区间就提示
- 比固定目标（如第三% 更稳健——避免市场暴跌时"必须满仓"导致无钱抄底

**为什么 4 投资类之和 = 97%（不是 100%）**：
- 剩余 3% 是现金区间下限之上的弹性空间（20%-23% 这段）
- 不强制 = 100% 给用户调仓自由度（不需要每次都精确凑满 100%）
