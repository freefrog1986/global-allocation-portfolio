## 目标

给 spec 096 周报卡片加 Section 2 — **大类资产配置策略**：在卡片上展示用户的三层资产配置策略，让用户一眼看出"现在持仓偏离策略多远"。

## 策略结构（四层 — 第十七轮最终）

### Layer 1（细粒度上限）：11 个 SwensenClass 子类各设上限

规则：**只设上限，不设目标**——子类占比超过上限时触发再平衡提醒。

### Layer 2a（投资类内部权重）：4 个超类按收益率排序的相对权重

| 超类 | 内部权重 | 排序依据 |
| --- | --- | --- |
| **股票**（CN/HK/US/FOREIGN_DM/EM 共 5 子类） | **70%** | 长期收益最高，"占大头" |
| **REITs**（CN_REIT/US_REIT 共 2 子类） | **15%** | 介于股债之间（收益 + 抗通胀） |
| **债券**（CN_GOV_BOND/US_BOND 共 2 子类） | **10%** | 中等收益 |
| **商品**（COMMODITY 1 子类） | **5%** | 不算投资资产，"长期没那么值钱" |
| **合计** | **100%** | 投资部分（不含现金） |

**实际目标 = 内部权重 × (1 − 当前现金占比)**

例：
- 现金 15%（子弹下限）→ 投资 85% → 股票目标 = 70% × 85% = 59.5%
- 现金 30% → 投资 70% → 股票目标 = 70% × 70% = 49%
- 现金 50%（子弹上限）→ 投资 50% → 股票目标 = 70% × 50% = 35%

### Layer 2b（现金区间 — 第十五轮新增，第十六轮放宽）："子弹"区间策略

**为什么不设固定目标走区间**：
- 股票/REITs/债券/商品属于"投资类"，追求收益
- 现金属于"子弹/弹药"，用于市场大跌时抄底 + 应对突发流动性需求
- 区间策略：常态下子弹保留 [15%, 50%]，市场大跌时有钱抄底

**为什么现金是区间不是目标**：
- 经济危机时需要大量现金抄底（子弹越多越好，但常态下不要打光）
- 现金有"机会成本"（投资收益跑赢现金），囤太多也是浪费
- 区间 [min, max] 提供"硬约束"：超出区间 → 调仓信号
  - 当前 < min：子弹打光了，要警惕（不能继续满仓投资）
  - 当前 > max：子弹囤太多，需要加仓投资类
  - min ≤ 当前 ≤ max：区间内，灵活

### Layer 3（子类内部权重 — 第十七轮新增）：每个超类内的子类固定比例

| 超类 | 子类 | 子类内部权重 | 依据 |
| --- | --- | --- | --- |
| **股票**（合计 100%） | A 股 | **40%** | 主场 |
| | 美股 | **20%** | QDII 费用 + 汇率风险，控制在 20% |
| | 港股 | **15%** | 大中华海外配置 |
| | 国外发达市场 | **15%** | 欧/日/台/韩合并（原亚洲发达 + 欧洲发达） |
| | 新兴市场 | **10%** | 分散 |
| **REITs**（合计 100%） | 国内 REITs | **70%** | 国内为主 |
| | 美国 REITs | **30%** | 国外为辅 |
| **债券**（合计 100%） | 国内利率债 | **70%** | 斯文森说信用债没阿尔法，国内信用债砍掉，4 只基金并入利率债 |
| | 美债 | **30%** | 海外避险 |
| **商品**（合计 100%） | 商品 | **100%** | 只有一个子类 |

**实际子类目标 = 子类内部权重 × 超类内部权重 × (1 − 当前现金占比)**

例（默认策略，现金 30%）：
- 投资部分 = 70%
- 股票超类目标 = 70% × 70% = 49%
- A 股目标 = 49% × 40% = **19.6%**
- 美股目标 = 49% × 20% = **9.8%**
- 港股目标 = 49% × 15% = **7.35%**
- 国外发达目标 = 49% × 15% = **7.35%**
- 新兴市场目标 = 49% × 10% = **4.9%**

**为什么新增 Layer 3（第十七轮核心变化）**：
- 之前只到超类（"股票 49%"），但用户实际想知道"具体每个子类的目标"
- "国内为主、国外为辅"是策略意图，要在子类层落地（不是抽象的"股票"层）
- 子类比例是固定的（不像超类随现金缩放）—— 反映长期资产配置意图

## 命名统一（第十七轮）

| 术语 | 含义 | 例 |
| --- | --- | --- |
| **大类资产** | 11 个 SwensenClass 子类（最小颗粒，飞书表格行） | A 股、港股、国内 REITs、国内利率债 |
| **超类** | 5 个聚合类（股票/REITs/债券/商品/现金，策略对比表行） | 股票、REITs、债券 |

**为什么统一命名（liubo 第十七轮反馈）**：
- 之前文档里"大类资产"和"超类"混用，卡片展示容易混淆
- 实际上："大类资产"指的是子类（最小颗粒，用户能买到的具体基金类型）
- "超类"是聚合类（按风险/收益类型分组，方便策略对比）
- 统一后用户一眼能区分："大类资产明细"看子类目标，"具体策略"看超类目标

- 分类（含 #. 前缀，例 "1. A 股股票"）：子类中文名

**为什么第二十轮恢复 Section 2（liubo 2026-09-19 反馈）**：

> "我还是要看一下超类的，因为我担心没控制好这个超类的比例了"

**Section 1 vs Section 2 的分工（不重复在哪）**：
- Section 1（持仓表）：11 行子类粒度（A股/港股/美股/.../现金）
  - target/delta 按子类公式算（subclass × super × (1-现金%)）
  - 用户看"具体某个子类偏离多少"
- Section 2（策略表）：5 行超类粒度（股票/REITs/债券/商品/现金）

- 两者 target 不严格相等（聚合路径不同），但都在小数点后 1 位误差内反映同一意图
- 这是不同聚合层级的视图，不是重复

**Section 3（子类对比表）不恢复的原因**：
- 第十九轮合并时已经把子类粒度的 target/delta 放进持仓表
- Section 2 恢复后，超类粒度有独立视图
- Section 3 是子类粒度的第二个视图 — 信息跟持仓表完全重复，不恢复

## 备注

**为什么是四层结构（第十七轮最终设计）**：
- Layer 1（上限）给"硬约束"——任何子类超过上限都触发警示，避免单一子类风险过度集中
- Layer 2a（投资类内部权重）给"软引导"——按收益率排序的相对权重反映策略意图（股票 > REITs > 债券 > 商品）
- Layer 2b（现金区间）给"弹性空间"——常态下子弹保留在区间内，危机时可加仓
- Layer 3（子类内部权重）给"具体落地"——"国内为主、国外为辅"的策略意图在子类层落地
- 四层结合：硬约束防止风险 + 软引导反映策略意图 + 弹性区间应对不确定性 + 具体落地反映配置细节

**为什么"只设上限不设目标"用于子类**：
- 子类级别如果强制目标比例会过度约束（市场短期波动会频繁触发再平衡）
- 只设上限更稳健：常态下不打扰用户，只在风险集中时介入

**为什么"现金走区间不走固定目标"**（第十五轮核心变化）：
- 现金本质是"子弹"（防御 + 抄底），不是"投资"（追求收益）
- 区间策略给用户保留弹性：常态下 15-50% 都行，但超出区间就提示
- 比固定目标（如第 3%）更稳健——避免市场暴跌时"必须满仓"导致无钱抄底

**为什么"投资类用内部权重而非绝对目标"**（第十六轮核心变化）：
- 现金区间 [15%, 50%] 是变量，投资部分也是变量
- 内部权重是不变的相对比例，绝对目标随现金自动缩放
- 这样调整现金时不用重新计算 4 个投资类目标（避免误操作）
- 内部权重反映真正的"策略意图"（按收益率排序），跟当前环境解耦

**为什么"子类也要用内部权重"**（第十七轮核心变化）：
- 用户想知道"具体每个子类的目标"——光说"股票 49%"不够细
- "国内为主、国外为辅"是策略意图，要在子类层落地
- 子类内部权重是固定的（不随现金缩放），反映长期配置意图

**第十七轮设计 vs 历史版本演进**：
- 第十四轮：4 投资类绝对目标 + 现金固定 3%
- 第十五轮：4 投资类绝对目标（合计 97%）+ 现金区间 [20%, 50%]
- 第十六轮（最终）：4 投资类内部权重（合计 100%）+ 现金区间 [15%, 50%]
- 第十七轮（最终）：4 投资类内部权重 + 11 子类内部权重 + 现金区间 [15%, 50%]

**第十八轮设计 vs 第十七轮**：
