# Spec 080: 飞书 Interactive Card 报告

> 状态：Draft
> 最后更新：2026-09-15

## 目标

把回测结果以飞书消息卡片（interactive card）形式发到当前话题。卡片含：
- 策略名 + 回测周期
- 资金曲线（line chart）
- 当前权重（pie chart）
- 关键指标表（CAGR / 夏普 / 最大回撤 / 波动率）
- 与基准对比（bar chart）

**不发 PNG 图片** —— 用飞书原生 chart 组件，支持 hover 和 series 切换，体验更好。

## 不在范围内

- 发到其他群（本期只发到当前话题 —— 用户明确）
- 发送按钮交互（callback 需要 webhook 服务，超出 MVP）
- 飞书文档写入（spec 085 后续）

## 数据契约

### `publish_backtest_report` 参数

```python
def publish_backtest_report(
    result: BacktestResult,
    chat_id: str | None = None,         # None = FEISHU_CHAT_ID env
    title: str | None = None,           # 默认 = result.strategy_id
    benchmarks: list[str] | None = None,  # 基准 ticker 列表
    dry_run: bool = False,              # True = 返回 card JSON，不真发
) -> str:                               # 返回 message_id
    ...
```

### 环境变量

| 变量 | 必需 | 说明 |
| --- | --- | --- |
| `FEISHU_APP_ID` | 是 | 飞书应用的 App ID |
| `FEISHU_APP_SECRET` | 是 | 飞书应用的 App Secret |
| `FEISHU_CHAT_ID` | 是 | 目标群 chat_id（`oc_xxx`） |

凭证从 `~/.config/gap/credentials.json` 或环境变量读，绝不 hardcode。

## 飞书 API 调用

用 [lark-oapi](https://github.com/larksuite/oapi-sdk-python)（飞书官方 Python SDK）。

```python
import lark_oapi as lark
from lark_oapi.api.im.v1 import CreateMessageRequest, CreateMessageRequestBody

client = lark.Client(app_id, app_secret)

request = CreateMessageRequest.builder() \
    .receive_id_type("chat_id") \
    .request_body(CreateMessageRequestBody.builder()
        .receive_id(chat_id)
        .msg_type("interactive")
        .content(json.dumps(card_json, ensure_ascii=False))
        .build()) \
    .build()

response = client.im.v1.message.create(request)
```

## 边界情况

1. **凭证缺失** —— 启动时报错 + 引导到 `docs/feishu-setup.md`
2. **chat_id 无效/无权限** —— 飞书 API 返回错误，原样上抛
3. **图表数据点 > 1000 个** —— 降采样到 1000 点（飞书图表性能限制）
4. **Equity curve 不足 2 个数据点** —— 报错"无足够数据画图"
5. **`dry_run=True`** —— 返回 card JSON 到 stdout，不调 API
6. **网络错误** —— 重试 3 次（指数退避），仍失败报错
7. **单卡片 > 30 KB** —— 飞书限制；分多张卡片发（按指标拆）

## 备注

- **不在终端渲染图表** —— 用户明确"飞书上看，终端不看"。CLI publish 直接发飞书，本地不存图
- **chart_spec schema** —— 见 [飞书官方文档](https://open.feishu.cn/document/uAjLw4CM/ukzMukzMukzM/feishu-cards/chart-components)
- **lark-oapi 的 `CreateMessageRequest`** —— SDK 1.2+ 才支持完整 card components
- **不是 botmux 的卡片** —— botmux 的卡片是简化版（只有 markdown + 按钮），不发 chart 组件。要发 chart 必须直接调飞书 API
- **凭证存储** —— MVP 只支持环境变量 + `~/.config/gap/credentials.json`。后续 spec 085 加 keyring 支持
